# 🛡️ SecureGuard Frontend

Легкий и безопасный генератор паролей, написанный на Vanilla JavaScript. Разработан с фокусом на UX и базовые принципы кибербезопасности.

### 🚀 Функционал
* Гибкая настройка длины пароля (от 8 до 64 символов).
* Выбор пула символов (заглавные/строчные буквы, цифры, спецсимволы).
* Алгоритм анализа энтропии для оценки криптостойкости пароля в реальном времени.
* Мгновенное копирование в буфер обмена одним кликом.

### 🛠 Стек технологий
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (без сторонних библиотек).
* **UI/UX:** Адаптивная верстка, Dark Theme в стиле GitHub.
